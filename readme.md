# INDIVIDUALLYST
 
 INDIVIDUALLYST 프로젝트 1차

가. 서비스 설명 : 
INDIVIDUALLYST는 투자자들이 특정 주식
에 대한 분석, 투자 근거, 목표 주가와 의견을 공유하고 토론
할 수 있는 투자 정보 커뮤니티 서비스이다.

나. 서비스 목표 : 
1.
 정확하고 근거 있는 투자 정보 공유
2. 허위 정보 및 근거 없는 
종목 추천 감소
3.
 신뢰할 수 있는 사용자를 구별할 수 있는 시스템 구축
- 커뮤니티 + 투자 특화(종목, 목표주가 등 여러 투자 관련 정보 공유를 편리하게 할 수 있음)

다. 서비스 타겟 : 
개인 투자자

라. 수익 모델 :
- (-) API비용, 서버 유지비용, 커뮤니티 유지비용
- (+) 월별 구독, 일반 사용자 광고 수익 

마. 서비스 기능 :
1. 회원가입·프로필 (자체)
2. 종목 검색·관심 종목 관리 (자체)
3. 투자 의견 작성 (자체)
4. 목표 주가·예상 기간 설정 (자체)
5. 근거·출처 첨부 (자체)
6. AI 팩트체크 (자체 + api openai api)
7. 댓글·찬반 토론 (자체)
8. 사용자 신뢰도 평가 (자체)
9. 투자 예측 결과 기록 (자체)
10. 종목별 커뮤니티 (자체)
11. 맞춤 알림 (자체)
12. 신고·관리자 관리 (자체)
